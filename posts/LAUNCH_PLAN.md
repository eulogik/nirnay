# Launch plan (all times IST, Thu Oct 1)

Goal: front page HN + top of r/LocalLLaMA + Dev.to evergreen. One rule
throughout: lead with the fine-tune caveat everywhere. HN finds it in ten
minutes if you hide it; stating it upfront turns it into the story
(fine-tune beats API on your own data).

## Order and timing

1. **Dev.to, now.** Evergreen canonical link. Everything else points here
   plus GH. No timing constraint.
2. **HN Show HN, 17:00 IST (07:30 ET).** Peak morning window. Poster stays
   in comments for 2 hours minimum. Title + body in launch_hn.md.
3. **Reddit, 20:00 IST.** r/LocalLLaMA first, r/MachineLearning 30 min
   later (different crowds, no brigading, never link the HN thread).
4. **X thread, with the Dev.to link, after HN is live.** Quote-post it
   once from @eulogik if HN gains traction.
5. **LinkedIn, Fri morning IST.** B2B angle. Company page + personal.

## Engagement rules (this is what makes it viral)

- Answer every technical question in the first 3 hours. Short answers,
  numbers attached, link to the exact file or table.
- Never argue. If someone is right, say so and cite what you will change.
  HN rewards this more than being right.
- Never correct the caveat defensively. It is in every post already.
- No vote asks anywhere (bans + backfire). No cross-posting links
  between threads.
- If a thread dies in hour one, let it die. Do not repost same-day.

## What not to do

- Do not submit to JevBench now (~#90 rank would poison every thread).
- Do not claim ONNX/GGUF/Space (not shipped; Space + Colab land next).
- Do not merge latency numbers across batch sizes and hardware.
- Do not publish Phase B as a separate story yet (save the second wave).
